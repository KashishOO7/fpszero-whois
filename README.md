# whois.fpszero.com

The personal library of Kashish Charaya (FPSZERO), security researcher.

**Live:** [whois.fpszero.com](https://whois.fpszero.com)

## What is on it

- **Shelves.** Writing on security, science, philosophy and everything else, shelved the way a library shelves books.
- **Workshop.** The projects: fpszero.com, Spectra, fpszero-lab, Svalekh and AEGIS.
- **Catalogue.** Every piece in one register.
- **Contact.** How to reach me.

## How it behaves

- Every page works with JavaScript switched off.
- No cookies, no analytics, no trackers.
- Nothing loads from another domain. Fonts, images and styles are all served from the site itself.
